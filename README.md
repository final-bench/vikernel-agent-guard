# ViKernel

**A firewall and security operations for AI models, by VIDRAFT.**

ViKernel judges the tool calls an AI agent proposes before they run, and shows the results on one security operations screen.

On the public ViKernel Scanner board (25 November 2026), 21 open models made 991 risky tool calls. After ViKernel Firewall, 0 went through.
